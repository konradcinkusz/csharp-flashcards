What it is

Study smarter.
One card at a time.

Each topic is a pair of Beamer slides: a question slide and an answer slide. Print them double-sided, use the PDF on your phone, or drive a live class — every card stands alone.

Section colour-coding makes it instant to jump to the area you want. Drop a new areas/*.tex file to add your own questions — no boilerplate required.

The PDF is built automatically on every tagged release via GitHub Actions + XeLaTeX. No local LaTeX install needed to get the PDF — just download from Releases.

Question
async/await
What is the difference between Task.WhenAll and Task.WhenAny?
Answer
async/await
WhenAll completes when all supplied tasks finish (or any faults). WhenAny completes as soon as the first task finishes — useful for timeouts and racing parallel operations.
Question
LINQ
When does a LINQ query actually execute — at definition or enumeration?
Answer
LINQ
Deferred execution: a LINQ query is defined as an expression tree and runs only when enumerated (e.g. foreach, .ToList()). Terminal operators like Count() or First() trigger immediate execution.

Quick start

Three ways to use the deck

No setup needed if you just want the PDF — grab it straight from GitHub Releases.

# Grab the latest compiled PDF — no LaTeX needed curl -L -o CSharp_FlashCards.pdf \ Actions → Build & Release PDF → Run workflow → download the artifact # Or visit the Releases page in your browser: https://github.com/konradcinkusz/csharp-flashcards/actions/workflows/ci.yml

A new PDF is published automatically whenever a v* tag is pushed. Bookmark the latest-release URL to always get the most recent version.

# Requires: XeLaTeX + latexmk (TeX Live or MiKTeX) git clone https://github.com/konradcinkusz/csharp-flashcards.git cd csharp-flashcards latexmk -xelatex -shell-escape main.tex # Output: main.pdf in the repo root # To add your own cards: # 1. Create areas/25-my-topic.tex (copy an existing file as template) # 2. Add \input{areas/25-my-topic} to main.tex # 3. Run latexmk again

Run latexmk -xelatex -shell-escape main.tex — it re-runs as many times as needed and handles all auxiliary files. Requires XeLaTeX for the custom font configuration.

# In Overleaf: # 1. New Project → Import from GitHub # 2. Authorise Overleaf to access your GitHub account # 3. Select konradcinkusz/csharp-flashcards # 4. Set compiler to XeLaTeX in Menu → Compiler # 5. Press Re-compile — done! # To sync changes back to GitHub: # Overleaf Menu → GitHub → Push to GitHub

Overleaf's built-in Git sync keeps both copies up to date. The project compiles with XeLaTeX — make sure to select it in the Overleaf compiler menu.

Trigger a release build

git tag v1.1.0
git push origin v1.1.0 # GitHub Actions builds the PDF and publishes the release
